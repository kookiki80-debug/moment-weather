# 🌿 모멘트 · Moment

**계산하고, 날씨를 확인하고, 오늘 할 일을 적는 나만의 작은 작업 공간입니다.**

계산기·현재 날씨·집중 타이머·메모를 한 화면에서 사용할 수 있는 웹 앱입니다. 앱 설치나 회원가입 없이 PC와 스마트폰의 브라우저에서 이용할 수 있습니다.

## 🚀 바로 사용하기

### [👉 모멘트 앱 열기](https://kookiki80-debug.github.io/moment-weather/)

위 링크를 누르면 바로 실행됩니다. 자주 사용한다면 브라우저 즐겨찾기에 추가해 두세요.

> 날씨를 불러오려면 인터넷 연결이 필요합니다. 현재 위치로 날씨를 확인하려면 브라우저에서 위치 권한을 허용해 주세요.

## ✨ 어떤 기능이 있나요?

| 기능 | 할 수 있는 일 |
| --- | --- |
| 🧮 계산기 | 사칙연산, 소수점, 퍼센트 계산을 마우스나 키보드로 입력 |
| 🌤️ 현재 날씨 | 선택한 지역의 기온, 체감 온도, 습도, 풍속 확인 |
| ⏱️ 집중 타이머 | 25분·50분 집중 또는 5분 휴식 시간 관리 |
| 📝 메모 | 할 일과 아이디어를 적고 현재 브라우저에 자동 저장 |
| 🕒 시계와 날짜 | 현재 기기의 시간과 날짜 확인 |

모바일에서는 화면 너비에 맞춰 카드가 세로로 배치됩니다.

## 📖 기능별 사용법

### 1. 현재 날씨 확인하기

1. 날씨 카드 왼쪽 위에서 **지역**을 선택합니다.
   - 서울, 부산, 인천, 대구, 대전, 광주, 제주를 지원합니다.
2. 현재 위치의 날씨가 궁금하다면 **현재 위치 버튼 `⌾`**을 누르고 위치 권한을 허용합니다.
3. 바로 다시 확인하려면 **새로고침 버튼 `↻`**을 누릅니다.

날씨는 앱이 열린 동안 **10분 간격으로 자동 갱신을 시도**합니다. 기온·체감 온도·습도·바람과 함께 데이터 기준 시각을 표시합니다. 실측값이 매초 바뀌는 서비스는 아니며, [Open-Meteo](https://open-meteo.com/)에서 제공하는 현재 날씨 데이터를 사용합니다.

### 2. 계산기 사용하기

화면의 숫자·연산 버튼을 누르거나 키보드로 입력하세요.

| 키 또는 버튼 | 동작 |
| --- | --- |
| `0`~`9`, `.` | 숫자와 소수점 입력 |
| `+`, `-`, `*`, `/` | 더하기, 빼기, 곱하기, 나누기 |
| `%` | 앞의 수를 100으로 나누기. 예: `10%` → `0.1` |
| `Enter` 또는 `=` | 결과 계산 |
| `Backspace` 또는 `⌫` | 마지막 글자 지우기 |
| `Escape` 또는 `AC` | 계산 초기화 |

예를 들어 `200*10%`를 입력하고 `Enter`를 누르면 `20`이 나옵니다. 곱셈·나눗셈을 덧셈·뺄셈보다 먼저 계산합니다. 메모를 입력하는 동안에는 계산기 단축키가 동작하지 않습니다.

### 3. 집중 타이머 사용하기

1. **25분 집중**, **50분 집중**, **5분 휴식** 중 원하는 시간을 선택합니다.
2. **시작하기**를 누릅니다.
3. 필요하면 **일시 정지**한 뒤 **이어 하기**로 다시 진행합니다.
4. 처음부터 시작하려면 타이머 옆의 **`↻`** 버튼을 누릅니다.

시간이 끝나면 앱 안에 완료 메시지가 표시됩니다. **소리 알림이나 운영체제 알림은 제공하지 않습니다.** 페이지를 새로고침하거나 닫으면 타이머는 초기화됩니다.

### 4. 메모 작성하기

**생각 한 조각** 입력란에 할 일이나 아이디어를 자유롭게 적으세요. 최대 10,000자까지 입력할 수 있고, 입력할 때마다 자동 저장됩니다. **메모 비우기**를 누르면 확인 후 내용을 삭제합니다.

> **메모 저장 시 꼭 알아두세요**
>
> - 메모는 서버나 GitHub가 아닌 **현재 브라우저의 저장 공간(localStorage)**에 저장됩니다.
> - 다른 기기나 다른 브라우저와 자동으로 동기화되지 않습니다.
> - 다운로드한 HTML 파일과 배포 사이트의 메모도 서로 공유되지 않습니다.
> - 브라우저의 사이트 데이터를 삭제하거나 시크릿 모드를 종료하면 메모가 사라질 수 있습니다.
> - 저장 불가 안내가 보이면 메모를 따로 복사해 주세요. 중요한 내용은 별도로 백업하는 것이 안전합니다.

## 💻 내 컴퓨터에서 실행하기

개발 도구나 별도의 패키지 설치 없이도 실행할 수 있습니다.

1. 이 저장소 위쪽의 **Code → Download ZIP**을 눌러 내려받습니다.
2. ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **`index.html`을 더블 클릭**해 브라우저로 엽니다.

날씨 조회와 웹 폰트 로딩에는 인터넷이 필요합니다. 로컬 파일에서 위치 조회가 제한된다면 지역을 직접 선택하거나 위의 배포 사이트를 이용하세요.

## 🗂️ 파일 구성과 사용 기술

```text
moment-weather/
├── index.html   # 화면 디자인, 계산기·날씨·타이머·메모 기능
├── README.md    # 프로젝트 소개와 사용 안내 (지금 읽고 있는 문서)
└── .nojekyll    # GitHub Pages에서 별도 변환 없이 파일을 제공하도록 하는 설정
```

- **HTML**: 화면의 내용과 구조
- **CSS**: 색상, 배치, 모바일 대응 디자인
- **JavaScript**: 계산, 날씨 조회, 타이머, 메모 저장
- **Open-Meteo API**: 별도 API 키 없이 날씨 데이터 조회
- **GitHub Pages**: 인터넷에서 앱을 열 수 있도록 무료 정적 사이트 호스팅

HTML·CSS·JavaScript가 `index.html` 한 파일에 들어 있습니다. 별도 서버나 빌드 과정이 필요하지 않습니다.

## 🔄 앱을 수정해서 GitHub에 올리기

이 저장소를 내려받아 Git 연결이 되어 있는 폴더에서 실행하는 방법입니다. 처음 한 번은 Git과 GitHub CLI 설치 및 `gh auth login` 로그인이 필요합니다.

아직 Git으로 내려받지 않았다면 다음 명령으로 시작하세요. 이미 저장소 폴더가 있다면 다시 내려받지 않아도 됩니다.

```sh
gh repo clone kookiki80-debug/moment-weather
cd moment-weather
```

`index.html` 또는 `README.md`를 수정하고 저장한 뒤, 터미널에서 다음 명령을 순서대로 실행합니다.

```sh
git status
git add index.html README.md
git commit -m "Update app and guide"
git push
```

| 명령어 | 쉬운 설명 |
| --- | --- |
| `git status` | 어떤 파일이 바뀌었는지 확인 |
| `git add` | 이번에 기록할 변경 파일 선택 |
| `git commit` | 변경 내용을 설명과 함께 내 컴퓨터에 기록 |
| `git push` | 내 컴퓨터의 기록을 GitHub에 업로드 |

**`main` 브랜치에 푸시하면 사이트도 자동으로 다시 배포됩니다.** 반영까지 잠시 걸릴 수 있으며, [Actions 페이지](https://github.com/kookiki80-debug/moment-weather/actions)에서 진행 상황을 확인할 수 있습니다. 배포 성공은 초록색 체크 표시로 나타납니다.

> `commit`은 내 컴퓨터에 기록하는 것이고, `push`는 그 기록을 GitHub로 보내는 것입니다. 앱 코드를 수정했다면 `push`까지 해야 배포 사이트에도 반영됩니다.

### GitHub Pages 설정 확인하기

이 저장소에는 이미 설정되어 있습니다. 다른 저장소에서 직접 배포할 때는 다음과 같이 설정하세요.

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치를 **`main`**, 폴더를 **`/ (root)`**로 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages에 표시되는 사이트 주소로 접속합니다.

## ❓ 문제가 생겼을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 날씨가 표시되지 않아요 | 인터넷 연결을 확인하고 날씨 카드의 `↻`를 눌러 주세요. API 서비스나 네트워크 문제일 수도 있습니다. |
| 현재 위치를 찾지 못해요 | 브라우저의 위치 권한을 확인하세요. 권한을 허용하지 않아도 지역을 직접 선택할 수 있습니다. |
| 메모가 다른 기기에서 안 보여요 | 정상 동작입니다. 메모는 작성한 브라우저에만 저장됩니다. |
| 수정했는데 사이트가 그대로예요 | `git push` 완료 여부와 Actions 배포 성공 여부를 확인한 뒤 브라우저를 새로고침하세요. |
| 인터넷 없이 사용할 수 있나요? | 내려받은 HTML의 계산기·타이머·메모는 사용할 수 있지만, 날씨는 인터넷이 필요합니다. 배포 사이트의 오프라인 실행은 보장하지 않습니다. |
